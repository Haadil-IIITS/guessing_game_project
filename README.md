🔢 Number Guessing Game<br>
A Python-based logic game where the player attempts to guess a randomly generated number between 1<br> and 100 within a limited number of attempts.<br>
<br>
📖 Description<br>
This program challenges the user to guess a secret number chosen by the computer. The game features<br> two difficulty levels that determine the number of lives (attempts) the player gets.<br> The program provides feedback on whether a guess is "Too High" or "Too Low" to help the user<br> narrow down the answer.<br>
<br>
I built this project to practice:<br>
<br>
The random module (generating random integers).<br>
<br>
Global vs Local Scope (managing variables).<br>
<br>
Control Flow (while loops and if/elif/else statements).<br>
<br>
Input Handling (setting difficulty levels).<br>
<br>
🚀 Features<br>
Difficulty Settings:<br>
<br>
Easy: You get 10 attempts.<br>
<br>
Hard: You get 5 attempts.<br>
<br>
Dynamic Feedback: Tells you if your guess is too high or too low.<br>
<br>
Win/Loss Logic: Automatically detects when you run out of guesses or find the correct number.<br>
<br>
🎮 How to Play<br>
Run the script.<br>
<br>
Type 'easy' or 'hard' to select your difficulty.<br>
<br>
Enter a number between 1 and 100.<br>
<br>
Read the feedback (Too High / Too Low) and guess again.<br>
<br>
Try to find the number before your lives run out!<br>
